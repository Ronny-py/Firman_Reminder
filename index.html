📲 Cara install di HP

  1. Download file APK Tekan tombol download di atas menggunakan browser HP (Chrome/Samsung Internet, dll).
  2. Izinkan install dari sumber tidak dikenal Saat pertama install, Android akan menampilkan peringatan. Ketuk "Setelan" pada peringatan tersebut, lalu aktifkan "Izinkan dari sumber ini" untuk browser yang kamu pakai.
  3. Ketuk file APK yang sudah terdownload Buka lewat notifikasi download atau folder "Downloads", lalu ketuk "Install".
  4. Buka aplikasi & izinkan notifikasi Saat pertama dibuka, aplikasi akan meminta izin notifikasi — ketuk "Izinkan" agar pengingat ayat bisa muncul.
  5. Aktifkan izin alarm presisi Aplikasi otomatis mengarahkan ke halaman Setelan untuk mengizinkan "Alarm & pengingat" — aktifkan supaya notifikasi tepat waktu.
  6. (Disarankan) Matikan optimasi baterai untuk app ini Buka menu Pengaturan di dalam aplikasi → ketuk tombol untuk mengizinkan aplikasi berjalan tanpa dibatasi baterai, supaya notifikasi tidak berhenti saat HP idle lama.
Catatan: Peringatan "aplikasi tidak dikenal" atau "Play Protect" itu wajar untuk APK yang tidak diunduh dari Play Store. Aplikasi ini tidak meminta akses internet untuk data pribadi apa pun — satu-satunya fitur yang membuka internet adalah tombol "Baca Pasal Lengkap".
